## Keeping it current

- A doc describes what the code does now, or is marked with a status line at the top (**not implemented**, **initial vision**). Proposals that were dropped are deleted, not kept.
- Finished work is deleted from ROADMAP, TODO and refactoring; what it changed for users goes to the CHANGELOG.
- Design notes name files and types, not line numbers.
- Generated files (`images/user-guide/`, `images/psg-visualization/`) are regenerated by their scripts, never edited by hand. Measurements and other one-off reports do not live here.
- File names are lower-case kebab-case; `ROADMAP.md`, `TODO.md` and `README.md` keep their conventional names.
